# Structured Database Environments

This repository showcases my experience working with relational databases using SQL. It highlights database design, data querying, and practical data operations through hands-on projects.

## 📌 Overview
The work in this repository demonstrates how structured data can be managed and analyzed using SQL. It includes building database schemas, establishing relationships between tables, and performing real-world data operations.

## 🛠️ Technologies Used
- SQL (MySQL)
- Relational Databases
- Codio (development environment)

## ⚙️ Key Skills Demonstrated
- Database design and schema creation
- Primary and foreign key relationships
- Data import from CSV files
- Data querying using SELECT, JOIN, WHERE, and GROUP BY
- Data analysis using aggregation functions (COUNT, percentages)
- Data manipulation (INSERT, UPDATE, DELETE)
- Data export to CSV files

## 📂 Projects Included

### 🔹 Project 1 – Database Setup & Data Operations
- Created a relational database from scratch
- Designed tables with proper relationships
- Imported data from CSV files
- Performed data manipulation (insert, update, delete)
- Exported processed data into output files

### 🔹 Project 2 – RMA Data Analysis
- Analyzed return data using SQL queries
- Identified return trends by state and product type
- Used JOINs and GROUP BY for data aggregation
- Calculated return percentages for business insights
- Summarized findings in a stakeholder-focused report

## 📊 Key Insights
- Return activity is concentrated in specific states
- Certain product types (e.g., higher port configurations) show higher return rates
- Data analysis can help identify potential product or operational issues
